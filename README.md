# KINGDOM Loops, Locks & Freedom Relations Atlas

This is the isolated Phase-0 producer for `kingdom.loops-locks-freedom-relations/0.1`.

It builds a closed, static and synthetic teaching record that keeps optimization, reinforcement learning, behavioral contingencies, control feedback, recurrence, cryptographic verification, authentication, authorization, enforcement and freedom-relevant conditions in distinct typed lanes. It does not rank people, infer minds, operate a reward or control loop, make access decisions, hold credentials, or perform actions.

## Public handoff

The only proposed public artifacts are:

- `/atlases/loops-locks-freedom-relations-atlas-2026-08-28.json`
- `/schemas/loops-locks-freedom-relations-atlas/0.1.json`
- `/LOOPS-LOCKS-FREEDOM-RELATIONS-ATLAS-v0.1.md`

The checked-in files under `public/` are pre-freeze review candidates until the record itself says `FROZEN_STATIC_FIXTURE`. There is no mutable alias, page, form, service, network adapter or runtime.

## Local verification

Node.js 20 or newer is sufficient. There are no dependencies and no install step.

```sh
npm test
npm run validate
npm run build
npm run build:check
npm run check
npm run overview
```

`build` can write only the three declared files under `public/`. Commands accept no paths and cannot publish externally.

## Reading discipline

The guide is the accessible linear reading. Equations also carry a plain-language reading and symbol table. The four behavioral contingency labels always spell out both the operation (`ADD` or `REMOVE`) and the observed response direction (`INCREASE` or `DECREASE`); color is never the sole carrier.

No relation in the atlas says that a valid signature makes content true, that a key grants authority, that reward establishes legitimacy, or that removing one technical constraint establishes freedom.
